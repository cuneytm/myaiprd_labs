# Claude modül 1 · Aynı işi üç yoldan, üç modelle

Portaldaki karşılığı: **Claude ile Çalışmak ve Uygulama Geliştirmek → 1. Claude ekosistemi ve modeller**, Lab 1.1.

Aynı NOC log özetleme işini önce Claude.ai'de, sonra Console Workbench'te, en son API ile üç modelde yapıp kaliteyi, süreyi ve maliyeti karşılaştırırsınız.

| Dosya | Kavram |
| --- | --- |
| `ornek-log.txt` | Kurgusal syslog: uplink düşmesi, BGP ve vPC olayları |
| `karsilastir.py` | Aynı isteği Haiku, Sonnet ve Opus'a gönderir; `usage` ve fiyat tablosundan maliyet hesaplar |

Adımlar [HOWTO.md](HOWTO.md)'de.
