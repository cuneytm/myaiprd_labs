# KB-139 · Yetkisiz telnet denemesi

## Belirti

AUTHPRIV telnet authentication failure.

## İlk kontrol

Telnet'in açık olmaması gerekir; feature telnet'i kontrol edin.

## Komutlar

- `show feature | i telnet`
- `show users`

## Çözüm

feature telnet'i kapatın, kaynak IP'yi güvenlik ekibine bildirin.

## DC1'e özgü not

Telnet DC1'de yasaktır; açık bulunması güvenlik olayıdır.
