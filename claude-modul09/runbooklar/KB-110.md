# KB-110 · Anycast gateway çalışmıyor

## Belirti

Sunucular varsayılan ağ geçidine ping atamıyor.

## İlk kontrol

fabric forwarding mode anycast-gateway ve anycast MAC'i kontrol edin.

## Komutlar

- `show run interface vlan <id>`
- `show fabric forwarding anycast-gateway-mac`

## Çözüm

SVI'da fabric forwarding mode anycast-gateway satırı olmalıdır.

## DC1'e özgü not

DC1 anycast gateway MAC adresi 2020.0000.00aa'dır; tüm leaf'lerde aynı olmalıdır.
