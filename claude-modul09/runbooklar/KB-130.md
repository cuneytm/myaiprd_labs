# KB-130 · DHCP relay çalışmıyor

## Belirti

İstemciler IP alamıyor.

## İlk kontrol

SVI'da ip dhcp relay address tanımını kontrol edin.

## Komutlar

- `show ip dhcp relay`
- `show run interface vlan <id>`

## Çözüm

Relay adresini ve DHCP sunucusuna erişimi kontrol edin.

## DC1'e özgü not

DC1 DHCP sunucuları 10.20.0.10 ve 10.20.0.11'dir; ikisi de relay'de tanımlı olmalıdır.
