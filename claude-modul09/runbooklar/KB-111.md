# KB-111 · Interface CRC hataları

## Belirti

CRC sayacı artıyor.

## İlk kontrol

Sayaç artışını 1 dakika arayla iki kez ölçün.

## Komutlar

- `show interface <port> counters errors`
- `show interface <port> transceiver details`

## Çözüm

Önce kabloyu, sonra optiği, sonra karşı ucu değiştirin.

## DC1'e özgü not

Optik RX gücü -10 dBm'in altındaysa optik veya fiber sorunludur.
